  `ubs <changed files>`. Failures go back to a worker with the exact assertion and a decision.
  Live tests are NOT RUN without a key.

  `git commit -- <paths>` (subject `<prefix>: … (<bead-id>)`, no trailers), `gitleaks git .
  --log-opts="origin/main..HEAD" --redact`, read the diff for local paths, push.

  plus `cargo publish --dry-run --locked --allow-dirty`, commit `chore: release X (bead)`, push,
  wait for CI success on that SHA, `bash scripts/release.sh <sha>`, verify release workflow,
  crates.io 200, `gh release view vX --json assets`.
